# Cyber Learning Journey 🛡️

Welcome to my cybersecurity learning journey! This repository tracks my 9-month roadmap to becoming a SOC Analyst. I will be documenting my daily progress, notes, labs, and projects here.

## 🎯 My Goal
To build a strong foundation in IT and Cybersecurity, develop hands-on SOC skills, and secure a Junior SOC Analyst role.

## 🗺️ The 9-Month Roadmap

- Phase 1: Foundations (Months 1-2)
  - Linux (OverTheWire Bandit)
  - Networking Basics
  - Python fundamentals
  - Professor Messer Security+ (Domains 1-3)
- Phase 2: Security Core (Months 3-4)
  - Professor Messer Security+ (All domains)
  - LetsDefend / Blue Team Labs Online
  - Phishing Analysis
- Phase 3: Hands-on SOC Skills (Months 5-6)
  - Build a Home SOC Lab (VirtualBox, Windows VM, Kali VM, Splunk/Wazuh)
  - Generate and detect failed logins
  - Write incident response reports
- Phase 4: Job-Ready Push (Months 7-9)
  - Polish GitHub Portfolio
  - Apply for internships and Junior SOC roles
  - Practice interview questions
